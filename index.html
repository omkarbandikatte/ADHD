The scientifically validated EEG signatures the model looks for.

Theta Band ↑ Elevated in ADHD

Frontal theta power is consistently increased in ADHD. Associated with inattention, working memory deficits, and reduced cortical arousal.

Beta Band ↑ Elevated in ADHD

Contrary to classical assumptions, clinical results show elevated frontal, central, occipital, and temporal beta activity in ADHD subjects relative to the normative reference in this dataset.

TBR is a historically referenced metric but is not used as a primary classification feature in this system. PSD band powers across all 19 channels are used instead for more robust spatial analysis.

Alpha Band ↑ Elevated in ADHD

Per the clinical prediction results, ADHD subjects show elevated frontal, central, parietal, occipital, and temporal alpha activity relative to the normative control reference — a key spatial biomarker in this framework.

L vs R frontal

Frontal Asymmetry Altered Pattern

Left-right alpha and theta asymmetry in the frontal lobe (Fp1/Fp2, F3/F4) is disrupted in ADHD, correlating with emotional dysregulation and attention control.

Sample Entropy ↓ Reduced Complexity

EEG complexity (measured by sample entropy) is lower in ADHD, suggesting more regular, less adaptive neural dynamics — particularly during cognitive tasks.

Backend Pipeline

Signal Processing Pipeline

Every step the system takes from raw .mat data to feature vectors.

1. Load .mat File

scipy.io.loadmat() — Reads 19-channel EEG matrix from the IEEE DataPort dataset (121 patients). Auto-detects variable names, sampling rate, and electrode labels.

2. Bandpass Filtering

Butterworth bandpass filter removes noise and focuses on meaningful brainwave bands. Filter equation: y[n] = Σ bₖ·x[n−k] − Σ aⱼ·y[n−j]. Notch filter at 50/60 Hz eliminates powerline interference.

3. ICA Artifact Removal

Independent Component Analysis (ICA) separates statistically independent sources from the mixed EEG. Removes eye-blink (EOG) and muscle (EMG) artifacts, isolating brain activity from different cortical regions.

4. Segmentation

The cleaned EEG signal is segmented around specific events into fixed-length windows. These segments serve as the input units for downstream feature extraction and model training.

5. PSD Feature Extraction

Power Spectral Density computed via: PSD(f) = (1/(fₛ·N)) · |Σ x[n]·e^(−j2πfn/fₛ)|². Captures signal power distribution across Delta, Theta, Alpha, Beta, and Gamma bands for all 19 channels.

6. CNN + TCN Deep Learning

CNN layer extracts spatial electrode patterns: yᵏᵢⱼ = f(ΣₘΣₙ wᵏₘ,ₙ · xᵢ₊ₘ,ⱼ₊ₙ + bᵏ). TCN layer captures long-range temporal dependencies using dilated causal convolutions with dilation d = 1, 2, 4, 8…

7. Clinical Explainability Output

Softmax classification head outputs ADHD / Non-ADHD prediction with a confidence score. The explainability component identifies abnormal spectral patterns per subject — elevated/reduced activity per cortical region relative to a normative control reference.

What are SHAP values?

SHAP is a game-theory-based method that assigns each feature a "responsibility score" for the model's prediction. It answers: "How much did elevated frontal theta power contribute to the ADHD diagnosis?"

Clinical Interpretation

The dashboard displays SHAP waterfall charts, force plots, and summary beeswarms — making it easy for neurologists to validate whether the model's reasoning aligns with clinical knowledge.

Not a Black Box

Every prediction can be traced back to specific EEG channels and frequency bands. Professors and clinicians can challenge, verify, and trust the output.

Dataset & Literature

Dataset & Research Background

Built on a publicly available clinical EEG dataset with a comprehensive review of 11 key papers.

IEEE DataPort Dataset

EEG recordings from 121 patients in MATLAB .mat format. 19-channel recordings covering frontal, temporal, central, parietal, and occipital regions. Includes ADHD patients and healthy controls across delta, theta, alpha, beta, and gamma bands.
